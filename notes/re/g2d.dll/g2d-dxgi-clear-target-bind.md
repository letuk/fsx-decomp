# G2D DX10 registered clear target binding

2026-11-15. Live verified in g2d.dll. The 299-byte body at 206db1e0
and 67-byte body at 206db8f0 match the pinned original PE SHA256

| Address | Evidence and behavior |
|---|---|
| 206db8f0, 2067a9a0 | Looks up the presentation window in a second ordered tree at registry +0x44. Returns whether the result differs from the sentinel at registry +0x48. This supersedes the provisional window-update interpretation. The path performs no window writes. |
| 206db1e0–206db238 | Target arrives in EAX, presentation window and options on the stack. A repeat bind clears target byte +0 and either resets the inline compositor when bytes +1 and +0x24 intersect or unbinds device views. Returns -1. |
| 206db23b–206db2b9 | Sets target +1 if options equal one. Queries the back-buffer descriptor through 206db540, packs the low 16 bits of width and height with high DWORD 0x12d, then acquires a resource through window +0x164 and stores it at target +0x18. Calls 206d8c40 with the five-DWORD descriptor 0x2d, 3, 0, 0, 0. |
| 206db2bb–206db308 | Calls 20679e60 when the compositor flags intersect. Otherwise calls device slot +0x60 with the color view at target +0x14 and the depth view from the wrapper when tag +0x20 equals two. Sets active byte +0 on success and propagates the observed downstream failures. |
