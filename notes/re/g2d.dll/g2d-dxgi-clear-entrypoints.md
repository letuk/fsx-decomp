| Address | Evidence and behavior |
|---|---|
| 20690570 | Table pointer at 20668c94. Returns true if the device at window +0x104 is absent. Otherwise uses window slots +0x38 and +0x20 for viewport width and height and calls device +0x78 and +0x7c to set the viewport and scissor. The optional rectangle supplies the scissor or defaults to the full viewport. If target +0x15c exists, converts RGB to floats, sets alpha and depth to 1 and clears color. A nonzero clear result returns false. |
| 206b9440 | Table pointer at 2066d30c. Checks renderer slot +0x194, then obtains the target through renderer +0x227b4 and window +0x15c. Clears with flags 7, black RGB, alpha and depth 1 and stencil zero. Returns zero regardless of clear status. |
| 206b94c0 | Table pointer at 2066d310. Uses the same target chain, converts all four ARGB channels to floats and forwards flags, depth and stencil. Returns zero regardless of clear status. |

The three pilot functions call the local clear selector. They use
fastcall entries with an unused EDX parameter to model the observed
ECX receiver and callee-cleanup stack arguments. Source signatures
are separate from final table binding. The shared RGB conversion
replaces repeated x87 sequences with C++ arithmetic.
