The pilot implements publication, unbinding and owner reset. It uses
an exact-key tree search that returns the target directly and an
in-order recursive walk for target destruction. The original uses
checked iterators. Target binding and presentation-window membership
were subsequently connected in [target binding](g2d-dxgi-clear-target-bind.md).
Target destruction and tree node deletion still have source boundaries.
The original window lifecycle callers still need source integration.

`param_3` to `registryKey` follows the lookup. Ghidra reads made
no database edits.
