The source in src/g2d-pilot/dxgi_shader_catalogue.h replaces the
catalogue constructor and initializer boundaries in the DXGI holder.
It uses fixed initial arrays for the observed twelve entries, validates
allocations and destroys an unpublished shader on initialization failure.
This cleanup is a source decision. The shader object constructor,
define copying, shader preparation, loading and stage-specific slot
targets remain explicit dependencies.
