src/g2d-pilot/dxgi_window_resources.h connects the three factory paths
to the existing reference-count helper. It reconstructs both window
holder shells and keeps catalogue construction, shader initialization,
constant buffer internals and registry cleanup as explicit boundaries.
The source adds failure checks for null allocations and a short shader
array, and frees unpublished tree storage on failure. The shader-related
original wrappers call their initializers even when allocation leaves
the holder null. The source returns -1 in that case.

VC8 x86 run g2d-dxgi-window-resources-20261112-002 compiled the G2D
unit with /EHsc and no compiler warnings. The first build treated
a C-linkage constructor as nonthrowing and warned on its cleanup.
The final build uses C++ linkage for the two potentially throwing
construction interfaces. Source snapshots match the workspace.
